1. Install the bookmark

Drag this button onto your bookmarks bar. It needs no add-ons or admin rights, so it works on TAFE machines. Press Ctrl+Shift+B if the bar is hidden.

Attendance → PeopleSoft

On a locked-down machine you can instead add a bookmark by hand and paste the code below as its address.

2. Use it

  1. Open the class roster in PeopleSoft for the date you want.
  2. Click the Attendance → PeopleSoft bookmark. A small window opens — allow popups if the browser blocks it.
  3. That window looks up who was present and copies the ID list to your clipboard.
  4. Back on the roster, a box asks for the list — press Ctrl+V, then OK.
  5. It ticks those students and tells you what it did.
  6. Check the grid, then click Save yourself.

The copy-paste step exists because TAFE's security settings stop the roster page from contacting this app, and stop the two windows talking to each other. Where those settings are looser the whole thing happens automatically and the window just closes itself — the bookmark handles both.

The bookmark never saves for you — attendance feeds funding and progress reporting, so the submission stays your call. It reads the meeting date straight off the roster.

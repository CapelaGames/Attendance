# TAFE NSW Attendance

Open `index.html` in a web browser. No installation required.

## First time setup

1. Click **Add student names** and paste your class list (one name per line), or click **Import CSV** to load an existing file
2. On Chrome/Edge, click **○ Link CSV for auto-save** in the header to link your CSV file — changes will save to it automatically. On other browsers, use **Export CSV** at the end of class

## Taking attendance

Students type their name in the search bar and tap their card to mark themselves present (turns green). Tapping again unmarks. A new date column is added automatically each week.

If a student isn't in the list, search their name and tap **+ Add "[name]" to class** — they'll be added and marked present.

## For the teacher

| Button | What it does |
|---|---|
| **Sort** | Toggle between first name / last name order |
| **Past Sessions** | Browse previous weeks (read-only) |
| **Full Sheet** | See all attendance in a table |
| **Export CSV** | Download the current data as a CSV file |

## Data

All data is stored in the browser's local storage and survives restarts. The linked CSV file (Chrome/Edge) is updated live on every tap.
